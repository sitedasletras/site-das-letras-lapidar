# Site das Letras — Lapidar

Lapidar é o sistema editorial do Site das Letras Edições Literárias.

Inclui:

- Ficha Global da Obra
- Plano Popular Diagramado (PPD)
- Certificado Editorial Lapidar
- Numeração sequencial global das obras
- Assinatura estrutural invisível dos arquivos
- Compatibilidade com UICLAP
- Compatibilidade com Amazon
- Compatibilidade com Clube de Autores
- Estrutura editorial automatizada

Projeto oficial em desenvolvimento.
