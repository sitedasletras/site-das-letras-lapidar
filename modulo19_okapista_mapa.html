OKapista — Mapa Estrutural

Aqui vestimos o seu livro para encontrar o mundo.

O OKapista constrói a apresentação visual externa da obra: capa, contracapa, lombada e orelhas. Este é o módulo que prepara o livro para o leitor antes mesmo da primeira página.

1. Entrada do módulo

O que o módulo recebe

  • Título da obra
  • Nome do autor
  • Sinopse
  • Biografia
  • Imagem de capa (se houver)
  • Formato editorial definido

O que o módulo não faz

  • Não faz diagramação do miolo
  • Não altera o texto interno
  • Não substitui Humanização
  • Não substitui Tradução

2. Elementos construídos

Estrutura visual externa

  • Capa
  • Contracapa
  • Lombada
  • Orelha dianteira
  • Orelha traseira

Resultado editorial

  • Identidade visual da obra
  • Apresentação profissional
  • Preparação para impressão
  • Preparação para plataformas digitais

3. Relação com o fluxo final

Posição no pipeline

  • Antes da Expedição
  • Após Diagramação
  • Após Humanização (quando houver)
  • Após Tradução (quando houver)

Última etapa visual

  • Finaliza a apresentação externa
  • Organiza materiais de capa
  • Prepara envio editorial
  • Entrega base para publicação
Aqui vestimos o seu livro antes de ele encontrar o mundo.
